WHAT YOU'LL SEE IN THE LOG
OK Traffic reached its destination — passed through your SASE client
BLOCKED SASE filtering blocked the request. HTTP mode usually shows 403; BROWSER mode often returns 200 because the block page itself is served with success — in that case the row says "Block page served (HTTP 200)"
CHALLENGE Cloudflare or CAPTCHA challenge page — not a SASE block, bot-check from the origin
WRN Warning — non-success HTTP status such as redirects or 4xx client errors
ERR Network error — timeout, DNS failure, SSL error, or connection refused
